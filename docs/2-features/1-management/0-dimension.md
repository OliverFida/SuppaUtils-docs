# Dimension-Locking
## Description
Enables admins to lock access to the nether or the end.

## Commands
### Admin-Commands
- **`/suppa dimension lock nether/end`**<br/>
  **Example:** /suppa dimension lock nether
- **`/suppa dimension unlock nether/end`**<br/>
  **Example:** /suppa dimension unlock end

## Default Config
- **netherLocked:** false
- **endLocked:** false
