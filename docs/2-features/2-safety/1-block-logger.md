# Block-Logger
## Description
Logs every change (breaking, placing, chaning inventory(e.g. chests)) of any block.

## Commands
### Admin-Commands
- **`/suppa safety enable/disable blocklogger`**
- **`/suppa safety clear blocklogger`**
- **`/blocklog`**<br/>
  Shows the block-log of the block the player is facing.

## Default Config
- **enabled:** false
