# Connection-Logger
## Description
Logs every (attempted) login and logout of any player.

## Commands
### Admin-Commands
- **`/suppa safety enable/disable connectionlogger`**
- **`/suppa safety clear connectionlogger`**
- **`/connectionlog <player>`**<br/>
  Shows the connection-log of the selected player.

## Default Config
- **enabled:** false
