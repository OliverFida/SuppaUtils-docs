# Introduction

SuppaUtils is meant to be a mod, making managing a community Minecraft server easier for the admin.<br/>
It allows the admin to provide QOL features, as well as safety features (for example limiting the amount of TNT a player can carry).

For a guide on how to install this mod, please continue [HERE](../getting-started/install).

For an overview over all available features, take a look [HERE](../features).
